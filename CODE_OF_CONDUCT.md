# Code of conduct

Everyone participating in this project should be treated with respect. This applies to repository issues, pull requests, reviews and other project discussions.

Be considerate of different backgrounds and experience levels. Give specific, constructive feedback about work. Accept corrections, acknowledge mistakes and allow others to participate. Disagreement about a technical choice is welcome; personal attacks are not.

Harassment, threats, discriminatory language, sexual attention, deliberate disruption and disclosure of another person's private information are unacceptable.

Maintainers may edit or remove disruptive contributions, close discussions, or restrict participation. They should explain moderation decisions when doing so would not expose private information or worsen harassment.

Report conduct concerns privately to a repository maintainer using the contact information they provide on their GitHub profile. If no private channel is listed, ask for one without posting the incident details. Include relevant links and the outcome you are seeking. Maintainers should handle reports discreetly and avoid sharing identifying details unnecessarily.
