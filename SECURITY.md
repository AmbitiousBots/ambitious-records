# Responsible disclosure

Please report suspected vulnerabilities privately. Do not post exploit instructions, credentials or private record data in a public issue or pull request.

Use GitHub's **Report a vulnerability** action in this repository's Security tab when it is available. If it is unavailable, ask a repository maintainer for a private reporting channel without describing the vulnerability publicly. Use only synthetic data in a reproduction.

Include the affected version, the command and minimal input that reproduce the issue, the expected and observed results, and the impact you believe it has. Remove tokens, private database contents and identifying information from logs and attachments.

Maintainers will assess the report, coordinate a fix where appropriate and discuss disclosure timing with the reporter. Avoid publishing details that would expose users before that discussion. No response or repair deadline is promised.
